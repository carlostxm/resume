# Resume

Hi! This is my resume repo. I'm keeping my CV in markdown format because it's easy to maintain, portable to other formats, and looks good on GitHub. Plus, it integrates nicely with tools like Astro!

## 📄 CV

[View my CV here](./CV.md) in markdown format.

## 🌐 Live Version

I built a simple web version with Astro that fetches the CV directly from this repo at build time. Deployed on Vercel with automatic preview deployments for every PR.

**Stack:**

- Astro 5 — static generation, zero JS
- Custom CSS — no frameworks, just clean styles
- Vercel — deployment + PR previews
- GitHub Actions — CI/CD pipeline
